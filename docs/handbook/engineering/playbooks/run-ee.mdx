---

The enterprise edition requires a postgres and redis instance to run, and a license key to activate.

<Steps>
<Step title="Run the dev container">

Follow the instructions [here](/build-pieces/misc/dev-container) to run the dev container.
</Step>

<Step title="Add the following env variables in `server/api/.env`">

Pase the following env variables in `server/api/.env`

```bash
## these variables are set to align with the .devcontainer/docker-compose.yml file
UNI_DB_TYPE=POSTGRES
UNI_DEV_PIECES="your_piece_name"
UNI_ENVIRONMENT="dev"
UNI_EDITION=ee
UNI_EXECUTION_MODE=UNSANDBOXED
UNI_FRONTEND_URL="http://localhost:4200"
UNI_WEBHOOK_URL="http://localhost:3000"
UNI_PIECES_SYNC_MODE='NONE'
UNI_LOG_LEVEL=debug
UNI_LOG_PRETTY=true
UNI_REDIS_HOST="redis"
UNI_REDIS_PORT="6379"
UNI_TRIGGER_DEFAULT_POLL_INTERVAL=1
UNI_CACHE_PATH=/workspace/cache
UNI_POSTGRES_DATABASE=united
UNI_POSTGRES_HOST=db
UNI_POSTGRES_PORT=5432
UNI_POSTGRES_USERNAME=postgres
UNI_POSTGRES_PASSWORD=A79Vm5D4p2VQHOp2gd5
UNI_ENCRYPTION_KEY=427a130d9ffab21dc07bcd549fcf0966
UNI_JWT_SECRET=secret
```

</Step>
<Step title="Activate Your License Key">
    After signing in, activate the license key by going to **Platform Admin -> Account -> Billing & subscription** and clicking **Activate license key**
    ![Activation License Key](/resources/screenshots/activation-license-key-settings.webp)
</Step>

</Steps>
